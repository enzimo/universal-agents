# Security Policy

## Supported versions

Security fixes are provided for the latest `0.1.x` release.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability or include
credentials, tokens, private data, or exploit details in public discussions.

Report vulnerabilities through the repository's private
[GitHub security advisory form](https://github.com/enzimo/universal-agents/security/advisories/new).
Include affected versions, reproduction steps, impact, and any suggested
mitigation. You should receive an acknowledgement within seven days.

If private vulnerability reporting is temporarily unavailable, wait for the
private channel to be enabled rather than publishing sensitive details.
