# Code of Conduct

Universal Agents is committed to a respectful, professional, and
collaborative community.

## Expected behavior

- Be constructive, patient, and considerate.
- Critique ideas and implementations rather than people.
- Respect differing backgrounds, experiences, and technical perspectives.
- Protect private information and report security concerns privately.
- Accept maintainer decisions intended to protect the project and community.

Harassment, discrimination, threats, deliberate disruption, doxxing, and
other abusive behavior are not tolerated in project spaces.

Maintainers may edit or remove contributions and restrict participation when
necessary to enforce these expectations. Report conduct concerns privately to
the maintainers through an appropriate private GitHub channel. Do not include
sensitive personal information in a public issue.
